## 2) C# record questions

Q: "is a record type reference, but record struct value?"

A: `record` is a reference type by default; `record struct` is a value type.

Q: "what does record add?"

A: Records add value-based equality, concise constructors, built-in `ToString()`, deconstruction support, and reduced boilerplate for data models.
